# Known issues: Intro Cutscene01

1. **The cutscene's Timeline assets are not in the project.** `Cutscene1.0.unity`'s two PlayableDirectors reference Timeline assets with GUIDs `6c754999587818b498193e98e38ca657` and `50b7538047e10b04c824eebc6b82fb2f`. No `.playable` file, or `.meta` with those GUIDs, exists anywhere outside `Library/`. Without them the directors have no asset, nothing animates and no audio plays. The runtime then shows the estimated subtitles and ends after `fallbackDurationSeconds` (66 s), or on Skip. **Fix:** import the two Timeline assets (and the animation clips and audio they use) together with the scene.
2. **Cinemachine is not installed.** The scene has a `CinemachineBrain` (script GUID `72ece51f2901e7445ab60da3685d6b5f`), but `com.unity.cinemachine` is not in `Packages/manifest.json`. Unity will show a missing script on the camera, and any Cinemachine tracks in the Timeline will not drive the camera. **Fix:** add the Cinemachine package version the cutscene was made with.
3. **Subtitle times are estimates.** Clip times could not be read (issue 1). The runtime times subtitles to the real Timeline clips automatically once the Timeline is present. The clip numbering assumes the track with the most clips is the one the user counted. If not, set `timelineTrack` in the JSON.
4. **The scene name has a dot.** Routing uses `Cutscene1.0`, the exact file name, because renaming the user's scene was out of scope. If `SceneManager.LoadScene("Cutscene1.0")` ever fails, rename the file to `Cutscene01.unity` in the Unity Project window (this keeps the GUID), then update `chapters.json`, `CareerProgressService`, `ProgressUI`, `Cutscene01Runtime.SceneName` and both regressions.
5. **"Alright..." uses three dots** instead of the ellipsis character, in case the UI font lacks the glyph. Change it in the JSON if the font has it.
6. **Skip is new.** The old intro's Skip button called a method that did not exist (`OnSkipPressed`), so it never worked. The new cutscene has a working Skip on repeat viewings that takes the same exit as the ending. First viewing deliberately hides and rejects Skip. Set `"showSkip": false` in the JSON to hide it.
7. The old `Level1_Character_Intro_Cutscene` stays enabled in the build list. Nothing loads it, so it only adds build size. Disable or remove it once the new intro is approved.

## Current Cutscene2.0 status — 2026-10-21

Routing now targets Cutscene2.0 and no runtime overlay subtitles/title card are built. The earlier missing-both-Timelines and subtitle-retiming notes are historical: EnvTimeline.playable is present for GUID 6c754999587818b498193e98e38ca657, while Cutscene2.0's other director still references absent GUID 50b7538047e10b04c824eebc6b82fb2f. Import that authored Timeline with its original metadata/bindings to restore its content; do not invent animation or rewrite the scene. Unity playback is pending. The existing skip/save contract remains unchanged. Authored text in the scene remains visible; only the generated overlay was removed.
