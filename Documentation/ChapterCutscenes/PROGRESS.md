### How the scene was built

No Editor automation. The scene YAML was generated by a scratch script (session scratchpad, not in the repository) that:

- copies `Office_Level1`'s `Environment/OfficeBuilding` hierarchy verbatim (1,741 objects, same fileIDs/world positions, ceiling and the office fill light included) **minus every object carrying a gameplay script** (receptionist, clients, Auditor, colleague, desk/corkboard/cabinet interactables, case-folder objects) and two couch/shelf instances with added children;
- adds 123 exterior prefab instances within 32 m (greenery, terrain, roads, sky) and the sun light (`Env/Directional Light`), flattened to world space under `Exterior (Office_Level1 copy)` so the windows look out on the same town;
- scene-local overrides only: the reception desk's `SM_Prop_Folder_Manila_04` copy is omitted (the Bayview folder takes its place) and the desk lamp copy is moved 6 cm west to clear the folder.

Composition was blocked numerically before writing: an offline renderer (FBX geometry + scene YAML, flat-shaded, actor bind poses) checked framing, eyelines, occlusion, subtitle space and 16:9 / 20:9 edges. These are **layout checks, not a visual review**.

### Skip, input, audio, cleanup

- Skip: same construction as `Cutscene01Runtime.BuildSkipButton` (HudTheme panel, BrassSoft “Skip” 36 bold, transparent hit area, upper-right in the safe area, −32/−32, 200×84). Shown on **every** viewing once the opening fade clears (0.25 s); one tap fades from the current opacity over 0.25 s; repeat taps are ignored. The original intro keeps its first-view gate.
- Android Back (Input System Escape) = Skip. In a standalone scene nothing else consumes it; when T04 loads this scene over another, that scene's Back handling must stand down while `ChapterCinematicPlayer.IsPlaying`.
- Clock: real (unscaled) time, at most 1/15 s per frame; pauses on focus loss/suspension (animators frozen, sources paused) and resumes at the same time. No `Time.timeScale` change.
- Audio follows the existing Effects setting (`AudioManager.IsSFXEnabled`, or the same PlayerPrefs key read-only when no manager exists) and fades with the Skip curtain. One AudioListener (on the scene camera); it disables itself if another live listener already exists.
- Finish (natural/skip/abort): sources stop, the curtain holds black, Skip hides; nothing is loaded or saved. A self-created EventSystem is destroyed with the scene.

### Completion contract for T04

```csharp
// Before loading the scene (optional): variant for relationship-aware lines (T02 onward).
ChapterCinematicPlayer.PendingContext = new ChapterCinematicContext("");

void OnCinematicFinished(ChapterCinematicResult result)
{
    ChapterCinematicPlayer.Finished -= OnCinematicFinished;
    // result.Id == "chapter01.end"; result.Outcome: Completed | Skipped | Aborted; result.PresentationTime
    if (result.Watched) { /* Completed or Skipped: continue to the Chapter 1 results/career flow */ }
    else { /* Aborted: torn down early; do not record a watched result */ }
}
```

- `Finished` fires after the closing fade reaches black (natural end at exactly 15.000 s; Skip 0.25 s after the tap). The scene then holds black until the caller loads/unloads.
- `ChapterCinematicPlayer.IsPlaying` / `Current` let the caller hold gameplay clocks and its own music while presenting. `Abort()` ends without a watched result; unloading the scene mid-play delivers `Aborted` (or `Skipped` if a Skip fade was running).
- The scene never calls `ApplyLevelResult`, `CommitLevelOneWrapUp`, handover/follow-through commands or intro-seen writes; T04 owns every progression step.
- **AudioManager**: it starts its office playlist (volume 0.035) in any scene not named `Cutscene1.0`/`Cutscene2.0`. T04 should add the `CS_*` scene names (or `ChapterCinematicPlayer.IsPlaying`) to that suppression; T01 does not edit the shared manager.
